# QFlowLearn

We build tools for creating, moving, and delivering assessments. Our work centers on Question and Test Interoperability (QTI), so assessment content can move between systems with its structure and scoring intact.

## Projects

| Project | Purpose | Availability |
| --- | --- | --- |
| **QFlow Author** | Create and review questions, organize banks, import existing assessments, and export QTI packages. | Open-source release planned; repository currently private. |
| **QFlow Deliver** | Publish assessments and manage learner attempts, timing, accommodations, results, and LMS connections. | Commercial platform; repository private. |
| [**QTI 3 library**](https://github.com/LongsightGroup/qti3) | Render, score, validate, and migrate QTI assessment content with TypeScript and a Web Component player. | Public; currently maintained under LongsightGroup. |

## Our intent

We plan to release QFlow Author as open source and build a community around practical assessment authoring and interoperability. The authoring project should be useful independently, including when you deliver assessments in another system.

We keep authoring, item rendering and scoring, and assessment delivery separate. The QTI library can support other applications. QFlow Deliver provides the commercial delivery platform, alongside hosted services and support.

Content portability guides the work: preserve the original, produce a useful supported export, and disclose any changes or omitted behavior. We want institutions and content teams to retain control of the assessments they create.
